# Night Shift Games

The studio website: <https://nightshift-games.com>, served by Cloudflare Pages from this repository (every push deploys).

- `/` - the studio
- `/barricaded/` - Barricaded Mixed Reality
- `/barricaded/privacy/` - Barricaded's privacy policy (`/privacy/` redirects there)
- `/barricaded/terms/` - Barricaded's terms of service (`/terms/` redirects there)

Plain HTML and one stylesheet (`assets/site.css`); no build step.
