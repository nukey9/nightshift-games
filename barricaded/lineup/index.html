Line-up QR code

Barricaded Mixed Reality · co-op · Player guide

When headsets playing together don't line up by themselves, a printed code does it: everyone looks at the same code, and you're lined up. It needs a Meta Quest 3 or 3S on Horizon OS v83 or later. See our Privacy Policy.

Print a code

One code is enough for a room. If you put codes in more than one room, use a different letter for each.

Code A

Print code A

  1. Print at 100% / Actual size (turn off “Fit to page”). The sheet has a 10 cm line to check your printer against.
  2. Use plain, matte paper, and keep it flat — no folds, curls or glossy laminate that shines.

Put it in your room

  1. Flat on the floor (taped down at the corners) where nobody will step or trip on it, or flat on a wall at about chest height. Not on a door, and not anywhere it might move.
  2. Somewhere well lit, in the room you play in.
  3. Leave it there for next time.

Line up with it

  1. The host: PLAY page → co-op box → Read the QR code. Look at the code from a step or two away and hold still a moment until the game says it has read it.
  2. Everyone else: once joined, Line up by QR code (on the PLAY page, or SETTINGS during a match). Look at the same code and hold still a moment — “Lined up by the QR code”.
  3. The step-by-step version, with pictures, is in the player guide.
